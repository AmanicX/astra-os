# Impeccable Design & Engineering Guidelines

1. **Anti-Slop Directives**:
   - Never generate default AI aesthetics (low-contrast grays, arbitrary floating pills, uncontained letterboxing).
   - Reject arbitrary containers: content must fill viewports purposefully.
   - Never hide or clip primary actions (e.g. Next/Proceed buttons must be permanently visible and docked).

2. **Visual Hierarchy & Contrast**:
   - Primary elements must pop with clear luminance contrast (minimum 4.5:1 ratio).
   - Secondary labels must remain crisp and readable (e.g., `#8e9ea9` or `#cbd5e1` on `#0b1220`).
   - Muted elements must never become unreadable mud.

3. **Spatial Rhythm & Alignment**:
   - Align elements along deliberate grid lines (padding 1-2 chars, consistent 8px/16px/24px rhythm).
   - Bottom bars must be anchored and distinct from scrollable content.
   - Action bars must have unambiguous button hierarchy: exactly one high-contrast primary CTA, muted secondary buttons.
