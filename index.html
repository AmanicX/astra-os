Features

Designed with intention.
Crafted with care.

Every detail of Astra Linux exists because someone thought hard about whether it should.

Scrollable Tiling

Niri arranges windows along an infinite horizontal ribbon. Fluid, ergonomic, and infinite workspace navigation powered by native Wayland.

Noctalia v5 Shell

A contemporary Wayland status bar, quick settings control center, workspace overview, and notification center unified in the transparent Noctalia palette.

Automated Setup Pipeline

A structured 9-stage interactive Bash installer (setup.sh) with auto-keepalive, automated ALPM compatibility, AUR helper setup, and headless non-interactive automation flags.

SilentSDDM & 10 Presets

Minimalist login greeter featuring 10 astronomical and daylight landscape themes (Daylight, Sunrise, Alpine, Earthrise, JWST Cosmic Cliffs), switchable via astra-sddm-theme.

Kitty, LazyVim & OpenCode

Kitty terminal with transparent Noctalia palette, Zsh with Oh-My-Posh (1_shell), pre-baked LazyVim with base16 sync, and the OpenCode terminal AI assistant.

Zero-Config Hardware & VMs

Automatic CPU microcode (Intel/AMD), GPU stacks (NVIDIA open drivers + DRM modesetting, AMD/Intel Mesa), and full VM guest integration (VirtualBox 3D, VMware, QEMU).

Hardware Specifications

Engineered for modern silicon.

Astra Linux runs bare-metal on 64-bit UEFI hardware and in virtualized environments.

CPU
Required

64-bit x86_64

Processor

Intel Core or AMD Ryzen with SSE4.2+ vector extensions. Automatic microcode detection (intel-ucode / amd-ucode).

RAM
4 GiB Floor

4 – 8 GiB

System Memory

4 GiB minimum, 8 GiB recommended. Niri + Noctalia maintains an exceptionally light idle footprint (~600 MB).

BASE
Distribution

Arch Linux

Base Installation

Any fresh minimal Arch Linux base system installed via standard archinstall or manual bootstrap.

PLATFORM
Universal

UEFI & VMs

Hardware & Hypervisors

Runs bare-metal on 64-bit UEFI hardware, or virtualized in VirtualBox (with 3D accel), VMware, and QEMU/KVM.

GPU
Accelerated

Mesa & NVIDIA

Graphics Stack

Open-source AMD and Intel Mesa & Vulkan; NVIDIA supported via nvidia-open drivers with DRM modesetting.

NET
Installer

Live Online

Connectivity

Active internet connection required during ./setup.sh to fetch desktop packages and compile AUR helpers.

Get Started

Transform your Arch base in minutes.

Install a minimal Arch Linux base system, then run the turnkey Astra Linux setup script.

01

Install Arch Base

Bootstrap a minimal Arch base using archinstall, reboot, and log in as a regular user with sudo privileges.

02

Clone Repository

git clone https://github.com/AmanicX/astra-os.git cd astra-os
03

Run Setup Script

./setup.sh

Automates all 9 installation stages.

✦ Unattended / Non-Interactive Automation
./setup.sh --aur paru --browser firefox --yes
